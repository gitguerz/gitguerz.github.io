01

Foundation

Claim the keys

Before design

The first WordPress skill is not picking a theme. It is knowing which account owns the domain, hosting, recovery email, and administrator access.

Exit ticket: You can name who controls the domain, the site account, the recovery path, and the place your decisions are written down.
02

Build & publish

Make the smallest real site

One page first

A one-page, truthful site you can update is more useful than a ten-page template you do not understand. Build a page, a menu, and one thing that invites a response.

What “small but real” means

Start with a homepage, an about/contact route or section, a page title and meta description, a clear navigation path, and one personally meaningful piece of original content. Add more only after the basics are usable.

Exit ticket: A visitor can understand what the site is, reach its key pages, and send a test contact message without you narrating the interface.
03

Care & security

Protect the boring parts

No plugin confetti

WordPress maintenance is a publishing practice. Backups, updates, roles, comments, and plugins are not exciting—until one breaks a site you need.

Before an update, run this tiny ritual
  1. Confirm you have a current backup and know where it lives.
  2. Check the update’s source and compatibility notes.
  3. Use staging when the host/platform offers it, or record how to roll back.
  4. Update one change group at a time; then test the public site and admin.
Exit ticket: You know how to recover, update, moderate, and hand the site back to yourself next month.
04

Publish proof

Do the public pass

Open a private window

The admin screen is not the website. Review the public URL like someone who has never met you, using an incognito/private window and a phone.

Exit ticket: The live site works for a new visitor, you can show what changed, and you know the next tiny maintenance date.

Battle test register

Before you call it published.

Use this as a quick failure-oriented pass. The point is not to become a security engineer overnight; it is to discover predictable breakage before visitors do.
