CSS Positioning Cold Build Instructional

CSS positioning changes how elements flow on the page. There are five values: static (default), relative, absolute, fixed, and sticky.

Static Positioning

Static positioning is the default value for all elements. Elements stack in normal document flow. Top, right, bottom, left properties do not apply; they are ignored.

I am static. I sit exactly where the document flow puts me.

Relative Positioning

Relative positioning moves an element from its normal position using top, right, bottom, left. It still takes up space where it would normally sit.

I am relative. I moved 20px from the top, but my original spot is still reserved.

Absolute Positioning

Absolute positioning removes an element from normal document flow. It positions relative to the nearest positioned ancestor (this section), not the whole page.

I am absolutely positioned inside my section, not flying to the top of the page.

Fixed Positioning

Fixed positioning anchors an element to the viewport. It stays in place even when you scroll. Removed from normal document flow.

I am fixed. I stay in place when you scroll.

Sticky Positioning

Sticky positioning is a hybrid. Element flows normally until you scroll past it, then it sticks to the viewport edge you defined.

I am sticky. I flow normally, then stick when you scroll.
