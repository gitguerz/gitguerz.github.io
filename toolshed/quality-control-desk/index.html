Parked · not this desk

Things that do not get to hijack the first useful release.

Parked by default. Paid SEO platforms, rank trackers, keyword-research campaigns disconnected from actual work, analytics-dashboard obsession, schema without a clear content purpose, and a WordPress/blog overhaul inside the static-site pass.

Unlock rule. A parked item needs a named site problem, evidence that the current desk cannot solve it, a small expected outcome, and a reason it deserves time now.

Mandatory linear notes · rights & accessibility

The fine print, written like a human.

Linear rule. Complete the floor before search setup; complete search setup before elaborate schema or discovery experiments; repair one observed problem before opening another audit tab.

Accessibility statement. This desk uses semantic headings and landmarks, keyboard-reachable controls, visible focus, text labels not dependent on color alone, responsive reflow, and reduced-motion support. It is workflow guidance, not a formal conformance certification.
