01

Editorial pass

Content truth

Read it like a stranger

The page does not need to say everything. It needs to say the true thing, clearly, without promising features or history that do not exist.

Pass condition: a stranger can explain what this page is, who made it, what it offers, and where its claims came from.

02

Interaction pass

Functionality

Click every thing

A polished page that has one dead button is not polished. Test what a person can actually touch—not just what looks good in a screenshot.

Minimum browser test set

Test one desktop browser, one second desktop browser, and a phone. Use a private/incognito window after each deploy so cache and old local data do not lie to you.

Pass condition: every visible control has a deliberate, reversible result or is removed.

03

People pass

Accessibility & resilience

Use a keyboard

The site should work for people who do not use your mouse, browser, connection, screen size, or attention bandwidth.

Pass condition: the page remains understandable and operable under common constraints, not just ideal conditions.

04

Release pass

Ship gate

Evidence or it didn’t happen

The last pass is not more tinkering. It is deciding the page is sufficiently true, functional, and traceable to publish.

Pass condition: you can point to the live URL, the commit, the review log, and the next small improvement—then walk away.
