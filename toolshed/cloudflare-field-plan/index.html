Fix GuerzBook’s Split-Brain Situation

1–2 weekends · security-sensitive
D1 + Turnstile

Replace “maybe it went somewhere” with one source of truth: a Cloudflare storage layer plus a protected API. D1 fits a moderated guestbook; only approved entries should ever be public.

Pick storage once, then stop reopening the decision
  • KV: fastest/simple wall, best if you want it shipped immediately.
  • D1: SQLite tables, better for moderation, replies, filters, and database practice.
  • Recommendation: D1—useful full-stack practice and a natural fit for structured guestbook entries.
