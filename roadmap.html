24-STEP WEB DEV ROADMAP

less fog, more forward

this is the map for turning html/css foundations into fullstack skills. no week numbers on purpose — some things take longer than a week, and that's not falling behind, that's how learning actually works. one date on the calendar: june 9, 2027 — full stack developer. everything between now and then flexes.
module 1: fCC responsive web design module 2: fCC javascript + front end libraries module 3: fCC backend apis + data viz goal: 6.9.27
you are here — the study gauntlet
the freeCodeCamp Responsive Web Design (fCC RWD) curriculum is done. now the material gets locked in before the exam — this is the hard part, not a victory lap.
daily structure (~45–60 min): 1) anki queue — 201-card handwritten deck, rate honestly. 2) build it cold — one concept from scratch, docs after. 3) touch a real fCC RWD cert project.
support lanes: Mimo (html + css paths) · Coddy · fCC RWD notes as the anchor.
next checkpoint: fCC RWD exam — taken when the deck feels solid, not on a date. module 2 begins after.
